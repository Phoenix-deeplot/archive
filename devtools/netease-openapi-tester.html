仅限本机开发测试

网易云音乐 OpenAPI 测试器

按网易云文档示例组装公共参数。App Secret、Access Token 都只在当前测试请求的内存中使用；页面不会生成或要求 RSA 私钥。

仅在本机使用：请从 http://127.0.0.1:8000 打开本页。凭据会随当前测试请求从浏览器发到本机转发器，再由它发往官方 openapi.music.163.com；它不会写入文件、浏览器存储、控制台日志或项目代码。不要将这个文件部署到 Vercel。

1. 填写当前接口所需凭据

自定义接口是否携带 Access Token / App Secret，按文档的“公共参数”开关决定。

严格匹配示例：GET /openapi/music/basic/recommend/songlist/get/v2、bizContent={"limit":100}、accessToken、device、当前毫秒 timestamp。示例没有 App Secret 与 sign。

该探测使用获取登录二维码接口。成功时应返回二维码地址或唯一键；这只能证明凭据和“用户登录”接口可用，不能自动证明歌单、榜单、播放 URL 等业务权限。

2. 怎么判断结果

填写该接口所需凭据后，点击“预览脱敏请求”。
推荐歌单的必要条件

只填 App ID 和 App Secret，不能替代 accessToken。这条接口是用户态请求：必须先走网易云授权，取得未过期的 Access Token；设备字段也必须带上。

code: 200：该接口已通过。
1405：App ID 无效。
1402：公共参数或接口鉴权不符合要求。
其他非 200：以官方 message、subCode 为准。

选择“自定义”时，路径、bizContent、是否带 Token / Secret 都按该具体接口文档设置；时间戳和 signType=RSA_SHA256 会自动带上。
