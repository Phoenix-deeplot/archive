# 收藏库使用说明

这篇本身就是一个 Markdown 文件，放在 `library/notes/` 里。它会被渲染成统一的阅读排版，和 HTML 笔记共用同一个阅读器。

## 添加内容

- **放进文件夹**：把文件放进 `library/books/`、`library/tools/`、`library/notes/` 或 `library/featured/`，刷新页面即可。
- **点“添加”或拖进页面**：运行 `serve.py` 时会直接写入对应文件夹。
- **新分类**：在 `library/` 下新建一个文件夹，它会自动出现在左侧。

## 支持的格式

| 格式 | 标题来源 | 摘要来源 | 阅读方式 |
| --- | --- | --- | --- |
| HTML | `<title>` | description 或导语段落 | 保留原网页的设计 |
| Markdown | front matter 或第一个 `#` 标题 | front matter 或第一段 | 统一的阅读排版，自动生成目录 |
| TXT | 第一行 | 后面的文字 | 统一的阅读排版 |
| PDF | 文档属性里的标题，否则用文件名 | 需要手动填写 | 浏览器自带的 PDF 阅读器 |

## 隐藏与恢复

卡片上的“隐藏”不会删除文件，只是让它不再出现在分类和搜索里。左侧最下方的 **已隐藏** 里可以随时恢复。

## Markdown 小技巧

在文件开头写 front matter，可以指定标题、摘要和关键词：

```markdown
---
title: 我的标题
description: 一句话摘要
tags: [供应链, 读书]
featured: true
---
```

> 图片可以用相对路径，例如 `![](images/chart.png)`，放在同一个文件夹里即可显示（需要通过 `serve.py` 或静态网站访问）。
