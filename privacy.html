隐私政策

本站是一个静态网站：没有账号、评论或表单，不要求你提交任何个人信息。下面如实说明访问本站时会发生什么。

本站不收集什么

  • 不收集、不存储访客的姓名、邮箱等个人信息。
  • 本站自己不设置 Cookie。
  • 没有广告，也没有 Google Analytics 之类的第三方统计脚本。

托管服务商的访问日志

本站托管在 Vercel。与所有网站一样，托管服务商会在服务器日志中记录访问的技术信息（例如 IP 地址、浏览器类型、访问的页面和时间），用于提供服务、安全防护和故障排查，并按其自己的隐私政策处理。站长不会用这些日志识别个人。

保存在你自己浏览器里的数据

为了让页面记住你的偏好，本站会在你的浏览器里保存一些数据，它们只存在你的设备上，不会发送到服务器：

  • 浏览器的本地存储（localStorage）：界面语言、主题、列表和排序偏好、阅读设置（字号、行距、版面宽度、阅读颜色）、阅读进度、你加的书签、你点过的星标和隐藏、你调整过的分类、封面选择。
  • 浏览器的 IndexedDB：你在页面上“添加”的文件（仅保存在这个浏览器里），你在“公共目录”里“收藏”的链接（只有标题、摘要和网址），以及你“连接”的本机文件夹的授权信息。
  • 浏览器的缓存（Service Worker）：为了让你装到主屏幕后能离线阅读，本站会把你打开过的页面和文件（最多 120 个，单个不超过 15 MB）连同首页保存在你的浏览器里。这些只在你的设备上，不会发送到服务器；清除本站数据即可删除。

你可以随时在浏览器的设置里清除本站的数据；也可以在页面上点“断开”，或删除你添加的文件。

“连接文件夹”

只有当你点击“连接文件夹”并在浏览器弹出的窗口里明确授权后，页面才能读取你选的那个文件夹。读到的文件只用来在你自己的浏览器里显示；当你点“添加”或“星标 / 隐藏”时，才会写入这个文件夹。文件内容不会离开你的电脑。你可以随时断开，也可以在浏览器的站点设置中撤销授权。

第三方资源

  • 页面使用 Google Fonts 加载字体（来自 fonts.googleapis.com 和 fonts.gstatic.com）。加载时你的浏览器会向 Google 发送请求（包含 IP 地址），由 Google 按其隐私政策处理。
  • 部分文章页面也可能使用相同的字体，或链接到其他网站；那些网站有各自的隐私政策。
  • 页面上的“订阅”会提供 Feedly、Inoreader 等阅读器服务的链接。只有你点击它们才会离开本站、访问对应的服务，它们按各自的隐私政策处理你的信息；本站不会知道你是否订阅。
  • 如果本站启用了“公共目录”：页面加载时（以及你打开它时），你的浏览器会向目录数据所在的站点（GitHub Pages）请求一份数据文件，GitHub 会按其隐私声明处理这次访问（包含 IP 地址）；目录里的封面图直接来自各个来源网站（请求不带本站地址），加载时那些网站能看到你的 IP 地址；点目录里的链接会离开本站去原网站。本站不会知道你看了哪些条目、收藏了什么。
  • 如果目录开通了在线提交：你在“收录”里提交的网址，或投稿的文章、标题、作者名、标签，会发送到目录的提交服务（托管在 Vercel）。点“检查”时，提交服务还会去读取你填的网址（只读公开页面，遵守 robots.txt），把读到的结果显示给你，不保存；提交后，它们被写成目录仓库（GitHub，公开）里的一个 issue，审核前所有人可见。提交服务不保存你的网络地址，只在 issue 里留一个加盐的、无法还原的短哈希，用来限制每人每天的提交次数。通过审核的文章会作为公开页面托管，署你填的作者名；被拒绝的投稿，其文字会从 issue 里清除，但 GitHub 可能保留编辑历史。想删除自己提交的内容，请通过“关于本站”里的联系方式或目录仓库的“下架”表单提出。

搜索引擎

本站允许 Google、Bing 等搜索引擎收录公开页面，站长会使用 Google Search Console 和 Bing Webmaster Tools 查看收录情况。这些工具提供的是页面层面的汇总数据，不会让站长看到某个具体访客。已隐藏的内容不会被发布。

儿童

本站不面向 13 岁以下儿童，也不会有意收集儿童的个人信息。

你的权利与联系方式

由于本站不收集个人信息，通常没有可供你查阅、更正或删除的数据；你浏览器里的数据由你自己控制。如对隐私有疑问，请联系：暂未公开。

政策变更

如果本站增加了新的功能（例如统计工具或评论），会先更新本页，并修改页首的“最后更新”日期。

Privacy. This is a static site: no accounts, no forms, no cookies set by the site, no ads and no third-party analytics. Settings, reading progress, files you add and a folder you connect are stored only in your own browser and are never sent to the server. The host (Vercel) keeps ordinary server logs (IP address, user agent, pages, time); fonts are loaded from Google Fonts, so your browser contacts Google. If the public directory is enabled, opening it requests a data file from GitHub Pages and loads cover pictures straight from the listed sites (without a referrer), so those hosts see your IP address; links you save from it stay in your browser. Hidden items are not published.
