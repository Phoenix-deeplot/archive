# 如何把「知树阅读」添加到主屏幕

装好以后：**全屏打开，像一个 App**；看过的页面和文件（最多 120 个，每个不超过 15 MB）**没有网络也能再读**；你加的文件、阅读进度、书签都留在这台设备上。

先打开：**https://books.zhitree.cn**

> ⚠️ **在微信 / QQ / 微博 里打开的页面装不了。** 点右上角「···」→「在浏览器打开」（iPhone 选 Safari，安卓选 Chrome），再按下面的步骤做。

---

## iPhone（Safari）

1. 用 **Safari** 打开 books.zhitree.cn（别用别的浏览器里的内置页）。
2. 点底部中间的 **分享** 按钮（方框加向上的箭头）。
3. 往下滑，点 **添加到主屏幕**。
4. 名字保持“知树阅读”，点右上角 **添加**。
5. 以后从主屏幕上的图标打开。

**一定要装**：iPhone 上不装到主屏幕的话，Safari 大约 **7 天不用** 就会清掉这个网站在你手机上存的东西（你添加的文件、阅读进度、书签）。装到主屏幕的不受这个限制。

## 安卓（Chrome）

方法一：打开 books.zhitree.cn，点页面里的 **「安装到主屏幕」**（旧版在左侧栏底部，新版在「设置」里）。

方法二：点 Chrome 右上角 **⋮** → **添加到主屏幕**（有的手机叫 **安装应用**）→ 确认。

装好后图标在桌面，点开就是全屏。

## 电脑（Chrome / Edge）

1. 打开 books.zhitree.cn。
2. 地址栏最右边会出现一个 **安装** 小图标（屏幕加向下的箭头），点它 → **安装**。
3. 或者：菜单 **⋯** → **应用** → **将此站点作为应用安装**（Edge）；菜单 **⋮** → **投放、保存和分享** → **安装页面为应用**（Chrome）。
4. 装好会在开始菜单 / 桌面有一个独立窗口。

---

## 装好之后还能做什么

- **没网也能读**：打开过的页面和文件会保存在手机里。
- **从别的 App 分享进来（安卓）**：在文件管理器、微信、浏览器里点“分享”，选“知树阅读”，PDF / Markdown / TXT / HTML 会打开“添加”窗口，网页地址会直接存成“收藏的链接”。要等浏览器更新应用信息（通常一天内）才会出现在分享列表里。iPhone 不支持这个，用“添加”多选文件。
- 分享进来的文件在你点“保存”之前只放在这个浏览器的临时缓存里，不会发到任何服务器。

## 常见问题

- **找不到“添加到主屏幕”**：多半是在微信等内置页里，或 iPhone 上没用 Safari。换浏览器打开。
- **安装按钮不出现（安卓）**：已经装过了，或浏览器还没准备好；用方法二（菜单）。
- **装了之后样子没变**：关掉重新打开一次；还是旧的就在设置里清一下这个网站的数据再打开（先“备份与恢复”导出，别丢东西）。
- **后台 / 锁屏播放**：安卓 Chrome 一般可以；iPhone 上网页和装到主屏幕的网页行为不一样，**没有在真机上验证过**，所以不保证。
