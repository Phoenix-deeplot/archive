## 正文

**【开头，换成你自己的真实起因，两三句：为什么做这个，之前你是怎么听歌、看热点、存文章的，什么地方让你烦。】**

下面不讲“做了什么功能”，讲一个普通人的一天，能在这个网页里做什么。

### 早上：它是我的随身电台

通勤的地铁上，我打开 books.zhitree.cn，点进“发现世界”里的「今日听什么」。

这一页每天换一批歌：每日推荐、华语热歌榜、欧美、韩流、日系，也有摇滚、说唱、古典、放松、专注这些风格。点一首，页面底部就长出一条播放条，再点「播放全部」，歌就一首接一首放下去。

有一件事要说清楚：**有的歌是 30 秒试听，有的是整首**，页面会在那一行标“试听”，不会让你以为是整首。喜欢哪首，点右边的小箭头，去原平台听全曲。

不用账号，这一页**不记录你听了什么**，也没有任何计数。

### 路上：它是我的播客架

听腻了歌，就把「今日听什么」顶上的“音乐”切到“播客”。

这里有热门播客、中国大陆 / 台湾 / 香港 / 美国 / 英国 / 日本的播客榜，也有新闻、商业、科技、英语学习、历史这些分类。点一集就播，倍速 0.75 到 2 倍，可以定时关闭（15、30、60 分钟，或者听完这一集就停）。读文章的时候，播放条会自己收起来，声音不会断。

如果你有自己常听的播客，贴它的 RSS 地址，就能订阅，新的一集会出现在你自己的书架里。**听到哪一集、听到哪里，只记在你自己的浏览器里**，下次打开接着听。

安卓 Chrome 上锁屏后一般还能继续放；iPhone 上我没有在真机上验证过，所以不敢保证。

### 中午：它是我的热点速览

午休的十分钟，我不想打开五个 App 看五个榜。

「热榜」把它们放在了一页，分成六栏：综合热点、科技与开发、财经、国际、AI 与学术、读书与影音。选一栏，旁边是这一栏的各个平台，右边是榜单：名次、标题、热度。点开的内容尽量在页面里直接看，平台不让显示的，才去原站。

有一个榜我想一直盯着，点「订阅这个榜单」，它就变成我书架里的一个合集，每次打开都是平台当前的榜。

### 晚上：它是我的发现页，也是我的书架

「发现」这一页从上到下是：今日 3 件值得看 → 编辑精选 → 值得订阅 → 最新更新。卡片上会写**为什么值得看**，但只写真实的理由：热榜第几名、你订阅的、站长推荐……没有就不写，不会编一个理由。

看到喜欢的：

- 点 ♥，表示喜欢；
- 点书签，存进「我的书架」；
- 想追更的博客或节目，点订阅。

「我的书架」不是一个抽象的概念。它是你自己的地方：你可以把 PDF、Markdown、TXT、网页小工具放进去，写读书笔记，记阅读进度，搜得到、读得顺。**这些只存在你自己的浏览器里，不会上传，别人看不到。** 换设备的时候，用“备份与恢复”导出一个文件，到新设备再恢复。

### 睡前：它是我的“专注”

学习、冥想、睡前，我会点一下「专注」。屏幕上只剩一个慢慢变化的图案（“呼吸”“极光”“暗”三种），加上声音，没有别的按钮，4 秒不碰就全部隐去。定时 15、25、45、60 分钟，到点自己停。

它只放**整首歌或整集节目**，30 秒试听不算。

## 你有什么故事

这个网页最想做的，是让“你自己的东西”有个不依附于任何平台的家：

- 你读过的书、记过的笔记、存过的文章，在你的书架里；
- 你订阅过的博客和播客，在你的合集里；
- 你听到哪、读到哪，在你的浏览器里。

没有账号、没有云端“画像”。你的故事不是我的数据。

## 你能怎么参与

- **喜欢和收藏**：♥ 会匿名计入热度，也会在你自己的浏览器里记一笔，让“发现”更贴你的口味（这份记录不离开你的设备，旁边有一键清除）；书签把一条链接存进你的书架。
- **订阅**：整站、某个分类、某个标签、某个热榜、某个播客，都能订阅，用你习惯的阅读器看。
- **写笔记**：在书架里直接写，Markdown 或所见即所得都行。
- **把好东西推荐给大家**：你有博客、有文章、有书单？点「收录」，贴一个网址，页面会先告诉你“这个已经有了”还是“可以提交”，**不用注册，也不用 GitHub 账号**。站长看过以后，它才会出现在“发现”里。目录里**只放标题、摘要和回到你原站的链接**，不存你的全文，点击都回到你自己的网站。
- **提意见**：哪里不顺手，直接告诉我。

## 它不做什么

- 没有统计脚本、没有 Cookie、没有广告。
- 不存别人的全文；公共目录只有标题、摘要、封面地址和链接。
- 你添加的文件，只在你自己的浏览器里。

## 装到手机主屏幕

iPhone：Safari 打开 → 分享 → 添加到主屏幕；安卓 Chrome：菜单 → 添加到主屏幕（或页面里的“安装到主屏幕”）。装好以后全屏打开，看过的页面没网也能读。

⚠️ **iPhone 一定要装**：不装的话，Safari 大约 7 天不用就会清掉你存在这个网站里的东西。在微信里打开的页面装不了，先“在浏览器打开”。

## 备用：回答类问题怎么切入

先真诚回答问题，再顺带提：

- “有没有不用注册的听歌 / 播客网站？”——先说清楚试听和整首的区别，再提这个。
