# 精选图书阅读做减法：最佳默认、悬浮字号条、书本式翻页（电脑 `‹` `›`、手机跟手滑动）、护眼切换（2026-11-03）

状态：**已确认（用户 2026-11-03：“确认你明白了我的需求，就开始改”）**，开发中

## 1. 任务清单（用户）

**范围：只改精选图书（书章）的阅读界面。文章、笔记、订阅、PDF、HTML 原样页面都不动。**

1. 不需要双页模式；去掉阅读里多余的设置，默认就用最佳阅读设置；**只保留字体大小**。
2. PC 端和手机端在**底部做一个悬浮窗**，可以调字体大小；PC 端翻页模式：有左右 `<` `>` 翻页，翻到底就进下一章。
3. 阅读页去掉“打开原页面”的图标，换成**护眼模式的切换**（点一下切换不同的颜色）。
4. PC 端读小说，按**书籍的样式**：中间是核心区域，显示文字或图片；查一下最佳阅读模式；操作上只保留基本切换，其余全是最佳默认。
5. 用户补充：专注阅读保留；手机上左右翻页**必须有**，只是现在有点生硬，要优化；电脑端用 `<` `>` 替代点击翻页；文章里的编辑笔记、精选不需要（文章本身这次不改，见范围）；书签在小说里不起作用，没必要就删。

## 2. 规划（Claude）

### 查到的依据（排版参数）

- **每行字数**：中文排版规范（W3C CLREQ）说书籍正文多在 17–40 字一行，横排最长不宜超过 48 字；WCAG 1.4.8 的上限是中日韩文本 ≤ 40 字一行、西文 ≤ 80 字符；西文网页常用 45–75 字符、约 66 最舒服。[CLREQ 讨论](https://lists.w3.org/Archives/Public/public-i18n-archive/2023JulSep/0019.html)、[设计文章（25–40 字）](https://www.woshipm.com/ucd/78869.html)、[Baymard](https://baymard.com/blog/line-length-readability)、[Oregon State 的行宽整理](https://blogs.oregonstate.edu/calverta/line-width-in-digital-typography-for-accessibility-and-comprehension/)。现在页面的“中”档是 44em（一行 44 个汉字），**偏宽**。
- **字号 / 行高**：网页正文 16–20px；行高 1.5 起步，行越长越要大，中文常用 1.7–1.9。
- 没有查到微信读书的具体数值，下面的数字按标准和惯例取，在预览里一起看。

### 书签

目录里的“书签”和顶栏“加书签”只对加进自己书架的东西起作用（`readerMark` 在 `!state.items.includes(it)` 时禁用）；精选图书是目录里的书（临时条目），所以是灰的。图书的位置另有自动记的一套（R1 的 `bk:<书>`：章、章内百分比）加章节面板，定位够用。**结论：图书里不要书签**（顶栏的按钮、目录面板的“书签”页都不出现）。文章不动。

### 精选图书章节的默认（用户不再能调，除字号）

| 项 | 默认 | 说明 |
|---|---|---|
| 字号 | 电脑 19px、手机 17px，用户可 80%–200%（每次 10%） | 唯一保留的设置，记在本机（和文章共用 `rs.fs`） |
| 一行字数 | 中文约 36 字（宽 36em），西文约 66 字符（宽 34em） | 按书的语言选 |
| 行高 | 中文 1.8，西文 1.65 | |
| 段落 | 首行缩进 2 字、段距小、中文两端对齐 | 书的样子 |
| 字体 | 保持现在的默认（系统字体） | 不加网络字体 |
| 阅读方式 | **翻页**（电脑和手机都是），书页居中；没有“滚动 / 翻页”开关，没有双页 | 含表格 / 代码 / 视频或图太多的章自动用滚动（R2 规则不变） |
| 颜色 | 默认跟随系统；“护眼”按钮点一下换下一种 | 跟随系统 → 米黄 → 护眼绿 → 深色 → 回到跟随系统；按钮上显示当前颜色，换的时候弹一句名字 |

文章不受影响：文章仍用 `rs` 里的行距、宽度、字体、段距、缩进、对齐和五种颜色（R1 的样子）。R2 加的 `mode`（阅读方式）、`dbl`（双页）两项设置**删掉**。

### 界面（精选图书章节）

- **顶栏**：返回 · 书名 / 章名 · 上一章 / 下一章 · 目录（章节面板，没有“书签”页）· 翻译（能翻译才出现）· 专注阅读 · 护眼（占“新标签打开”的位置）。去掉：阅读设置 Aa、保存、书签、星标、新标签打开。
- **底部悬浮窗**（电脑和手机）：`A−  100%  A+` 和读到哪（`第 3 / 12 页 · 第 5 章`）。电脑上半透明，鼠标靠近变清楚；手机上点正文中间和顶栏一起出现 / 收起；手机上“上一章 / 下一章”也放进去（替换现在的 `reader-mobile-nav`）。专注阅读时它和顶栏一起收起。
- **电脑翻页**：书页在屏幕**正中**，纸色的一页，两边是略深的底；页的左右两边各一个大的 `‹` `›`（只在鼠标指针的设备上出现）；键盘 ← → / PgUp PgDn / 空格 / Home / End、滚轮保留；**点正文不再翻页**（避免误点和选字时翻页）；翻页有 200ms 的滑动（尊重系统的“减少动态效果”）；最后一页再翻 = 下一章第一页，第一页回翻 = 上一章最后一页（R2 已做）。
- **手机翻页（优化现在的“生硬”）**：保留左右滑动和点两侧 30%、点中间收起 / 显示栏；改成**页面跟着手指走**（拖动时看得到下一页的边），松手后按距离和速度**吸附**到本页或翻页（带缓动，不是瞬间跳）；点两侧也有同样的滑动；竖向滑动不响应（翻页模式里没有竖向滚动）；首页向右滑 / 末页向左滑 = 上一章末页 / 下一章首页（现在已经是这样，加同样的动画）。
- 图片按页高等比缩放，居中。
