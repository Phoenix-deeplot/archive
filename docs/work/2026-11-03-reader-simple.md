## 2. 规划（Claude）

### 查到的依据（排版参数）

- **每行字数**：中文排版规范（W3C CLREQ）说书籍正文多在 17–40 字一行，横排最长不宜超过 48 字；WCAG 1.4.8 的上限是中日韩文本 ≤ 40 字一行、西文 ≤ 80 字符；西文网页常用 45–75 字符、约 66 最舒服。[CLREQ 讨论](https://lists.w3.org/Archives/Public/public-i18n-archive/2023JulSep/0019.html)、[设计文章（25–40 字）](https://www.woshipm.com/ucd/78869.html)、[Baymard](https://baymard.com/blog/line-length-readability)、[Oregon State 的行宽整理](https://blogs.oregonstate.edu/calverta/line-width-in-digital-typography-for-accessibility-and-comprehension/)。现在页面的“中”档是 44em（一行 44 个汉字），**偏宽**。
- **字号 / 行高**：网页正文 16–20px；行高 1.5 起步，行越长越要大，中文常用 1.7–1.9。
- 没有查到微信读书的具体数值，下面的数字按标准和惯例取，在预览里一起看。

### 书签

目录里的“书签”和顶栏“加书签”只对加进自己书架的东西起作用（`readerMark` 在 `!state.items.includes(it)` 时禁用）；精选图书是目录里的书（临时条目），所以是灰的。图书的位置另有自动记的一套（R1 的 `bk:<书>`：章、章内百分比）加章节面板，文章也自动记读到哪（`progress`）。**结论：书签整个去掉**（顶栏的按钮、目录面板的“书签”页、`addMark` 等代码都删）。已经存在的书签数据（`archive.marks`，随备份和同步走）不动，只是没有界面了。

### 所有文字阅读的默认（用户不再能调，除字号和护眼颜色）

| 项 | 默认 | 说明 |
|---|---|---|
| 字号 | 电脑 19px、手机 17px，用户可 70%–200%（每次 10%） | 唯一保留的设置，记在本机（`rs.fs`） |
| 一行字数 | 中文约 36 字（宽 36em），西文约 66 字符（宽 34em） | 按文章 / 书的语言选（没有语言就看标题和摘要有没有汉字） |
| 行高 | 中文 1.8，西文 1.65 | |
| 段落 | 图书：首行缩进 2 字、段距小、中文两端对齐；其他文字：不缩进、段距 1.1em、左对齐 | 按“是不是图书”自动选 |
| 字体 | 保持现在的默认（系统字体） | 不加网络字体 |
| 阅读方式 | **图书翻页**（电脑和手机都是），书页居中；其他文字竖向滚动；没有“滚动 / 翻页”开关，没有双页 | 含表格 / 代码 / 视频或图太多的章自动用滚动（R2 规则不变） |
| 颜色 | 默认跟随系统；“护眼”按钮点一下换下一种 | 跟随系统 → 米黄 → 护眼绿 → 深色 → 回到跟随系统；按钮上显示当前颜色，换的时候弹一句名字 |

`rs` 里只剩 `fs` 和 `th`：旧的行距、宽度、字体、段距、缩进、对齐、`mode`、`dbl` 不再读（不删用户本机的数据）。“阅读设置（Aa）”按钮和面板整个删掉（里面的“专注阅读”和“翻译”两行：手机上点正文中间收起 / 显示栏就是专注阅读，翻译用屏幕角上的圆形小按钮 `#trFab`，现在所有文字都有）。

### 界面

- **图书章节的顶栏**：返回 · 书名 / 章名 · 上一章 / 下一章 · 目录（章节面板，没有“书签”页）· 翻译（能翻译才出现）· 专注阅读 · 护眼（眼睛图标，点一下换颜色，占“新标签打开”的位置）。去掉：阅读设置 Aa、保存、书签、星标、新标签打开。
- **文章（笔记、订阅、目录里的文章）的顶栏**：返回 · 标题 · 上一篇 / 下一篇 · 播放（有音频才有）· 专注阅读 · 翻译 · 目录 · 保存 · 护眼。去掉：Aa、书签、星标、编辑笔记（卡片上本来就有）、新标签打开（原文的链接在文末）。
- **PDF / HTML 原样页面**：去掉 Aa，加护眼（颜色）；“新标签打开”照旧。
- **底部悬浮窗**（所有文字，电脑和手机）：`A−  页码或百分比  A+`（图书：`3 / 12`，手机上两边还有上一章 / 下一章，替换现在的 `reader-mobile-nav`；文章：`45%`，手机上文章的 `reader-mobile-nav` 仍在）。电脑上半透明，鼠标靠近变清楚；手机上点正文中间和顶栏一起出现 / 收起；专注阅读时它和顶栏一起收起。
- **电脑翻页**：书页在屏幕**正中**，纸色的一页，两边是略深的底；页的左右两边各一个大的 `‹` `›`（只在鼠标指针的设备上出现）；键盘 ← → / PgUp PgDn / 空格 / Home / End、滚轮保留；**点正文不再翻页**（避免误点和选字时翻页）；翻页有 200ms 的滑动（尊重系统的“减少动态效果”）；最后一页再翻 = 下一章第一页，第一页回翻 = 上一章最后一页（R2 已做）。
- **手机翻页（优化现在的“生硬”）**：保留左右滑动和点两侧 30%、点中间收起 / 显示栏；改成**页面跟着手指走**（拖动时看得到下一页的边），松手后按距离和速度**吸附**到本页或翻页（带缓动，不是瞬间跳）；点两侧也有同样的滑动；竖向滑动不响应（翻页模式里没有竖向滚动）；首页向右滑 / 末页向左滑 = 上一章末页 / 下一章首页（现在已经是这样，加同样的动画）。
- 图片按页高等比缩放，居中。
