## 1. 任务清单（用户）

1. 不需要双页模式；去掉阅读里多余的设置，默认就用最佳阅读设置；**只保留字体大小**。
2. PC 端和手机端在**底部做一个悬浮窗**，可以调字体大小；PC 端翻页模式：有左右 `<` `>` 翻页，翻到底就进下一章。
3. 阅读页（图书或文章）去掉“打开原页面”的图标，换成**护眼模式的切换**。
4. PC 端读小说，按**书籍的样式**：中间是核心区域，显示文字或图片；查一下最佳阅读模式怎么设置；操作上只保留基本切换，其余全是最佳默认。

## 2. 规划（Claude）

### 查到的依据（排版参数）

- **每行字数**：中文排版规范（W3C CLREQ）说书籍正文多在 17–40 字一行，横排最长不宜超过 48 字；WCAG 1.4.8 的上限是中日韩文本 ≤ 40 字一行、西文 ≤ 80 字符；西文网页常用 45–75 字符、约 66 最舒服。[CLREQ 讨论](https://lists.w3.org/Archives/Public/public-i18n-archive/2023JulSep/0019.html)、[设计文章（25–40 字）](https://www.woshipm.com/ucd/78869.html)、[Baymard](https://baymard.com/blog/line-length-readability)、[Oregon State 的行宽整理](https://blogs.oregonstate.edu/calverta/line-width-in-digital-typography-for-accessibility-and-comprehension/)。现在页面的“中”档是 44em（一行 44 个汉字），**偏宽**。
- **字号 / 行高**：网页正文 16–20px；行高 1.5 起步，行越长越要大，中文常用 1.7–1.9。
- 我没有查到微信读书的具体数值，下面的数字是按上面的标准和惯例取的，做出来在预览里一起看。

### 定下来的默认（用户不再能调，除字号）

| 项 | 默认 | 说明 |
|---|---|---|
| 字号 | 电脑 19px、手机 17px，用户可 80%–200%（每次 10%） | 唯一保留的设置，记在本机 |
| 一行字数 | 中文约 36 字（宽 36em），西文约 66 字符（宽 34em） | 按文章语言选 |
| 行高 | 中文 1.8，西文 1.65 | |
| 段落 | 图书：首行缩进 2 字、段距小、中文两端对齐；文章：不缩进、段距 1em、左对齐 | 按“图书 / 文章”自动选 |
| 字体 | 保持现在的默认（系统字体） | 不加网络字体，避免离线和加载问题 |
| 阅读方式 | **图书 + 宽屏（≥ 900px）= 单页翻页**；手机和文章 = 竖向滚动 | 没有“滚动 / 翻页”开关 |
| 颜色 | 默认跟随系统；“护眼”打开 = 米黄纸色 | 见“待你定的” |

旧的阅读设置（行距、宽度、字体、段距、缩进、对齐、阅读方式、双页、五种颜色）在读取时**忽略**，不删用户本机的数据，但不再起作用。

### 界面

- **顶栏（图书和文章）**：返回 · 书名 / 章名 · 目录 · 翻译（能翻译才出现）· **护眼**（原来“新标签打开”的位置）。去掉：阅读设置 Aa、专注阅读按钮、新标签打开。
- **底部悬浮窗**（电脑和手机都有，图书和文章）：`A−  100%  A+` 和读到哪（翻页：`第 3 / 12 页 · 第 5 章`；滚动：`45%`）。电脑上半透明，鼠标靠近变清楚；手机上点正文中间和顶栏一起出现 / 收起。手机上“上一章 / 下一章”也放进去（替换现在的 `reader-mobile-nav`）。
- **电脑端翻页**：书页在屏幕**正中**，纸色的一页，两边是略深的底；页的左右两边各一个大的 `‹` `›`（点页边也能翻）；键盘 ← → / PgUp PgDn / 空格、滚轮、点击左右 30% 保持；最后一页再翻 = 下一章第一页，第一页回翻 = 上一章最后一页（这些 R2 已经做好）；图片按页高等比缩放，居中。
- 含表格 / 代码 / 视频或图太多的章节仍自动用滚动（R2 的规则不变），但不再有说明文字（没有设置了）。
- PDF 和 HTML 原样页面：顶栏保持现在的样子，只是“新标签打开”照旧保留（它们没有“最佳设置”可言）；护眼切换对它们同样可用（用现在的色调遮罩）。

### 待你定的三点（我的建议排在前面，没改就按建议做）

1. **手机端**：默认竖向滚动（点中间显示 / 收起栏）。如果你想手机也翻页，我再加（宽度 < 900px 也用单页翻页，点左右 30% 翻页）。
2. **护眼切换**：开 = 米黄纸色（深色系统下保持深色，只把白换成偏暖的深色），关 = 跟随系统。如果你想要“护眼绿”或者“跟随系统 → 米黄 → 深色”三档循环，说一声。
3. **被去掉的按钮去哪了**：图书只留上面那几个（位置自动记，不需要书签 / 星标 / 保存）；**文章**（自己的笔记、订阅的文章、保存的网页）在护眼后面多一个“⋯”菜单，里面放：加书签、精选、保存、编辑笔记、新标签打开，这样原页面还能打开。如果你要彻底删掉它们，说一声。
