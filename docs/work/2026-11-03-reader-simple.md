## 2. 规划（Claude）

### 查到的依据（排版参数）

- **每行字数**：中文排版规范（W3C CLREQ）说书籍正文多在 17–40 字一行，横排最长不宜超过 48 字；WCAG 1.4.8 的上限是中日韩文本 ≤ 40 字一行、西文 ≤ 80 字符；西文网页常用 45–75 字符、约 66 最舒服。[CLREQ 讨论](https://lists.w3.org/Archives/Public/public-i18n-archive/2023JulSep/0019.html)、[设计文章（25–40 字）](https://www.woshipm.com/ucd/78869.html)、[Baymard](https://baymard.com/blog/line-length-readability)、[Oregon State 的行宽整理](https://blogs.oregonstate.edu/calverta/line-width-in-digital-typography-for-accessibility-and-comprehension/)。现在页面的“中”档是 44em（一行 44 个汉字），**偏宽**。
- **字号 / 行高**：网页正文 16–20px；行高 1.5 起步，行越长越要大，中文常用 1.7–1.9。
- 没有查到微信读书的具体数值，下面的数字是按上面的标准和惯例取的，做出来在预览里一起看。

### 书签为什么在小说里不起作用（查过代码）

目录里的“书签”页和顶栏的“加书签”只对**加进自己书架的东西**起作用（`readerMark` 在 `!state.items.includes(it)` 时禁用）；精选图书是目录里的书（临时条目），所以按钮是灰的。位置本身另有一套：精选图书的“读到哪一章、章内多少”自动记（R1 的 `bk:<书>`），每章章节面板也能跳。

**结论：图书里删掉书签**（顶栏的按钮和目录面板的“书签”页都不出现）。理由：书签的作用是“定位”，图书已经有自动记位置 + 章节面板；真要做“记住某一段”那是划线 / 笔记，是另一个功能，这次不做。**文章**里书签保持现在的样子（自己书架里的文章有用），但目录里的文章（没加进书架的）不再显示灰的按钮，直接不显示。

### 定下来的默认（用户不再能调，除字号）

| 项 | 默认 | 说明 |
|---|---|---|
| 字号 | 电脑 19px、手机 17px，用户可 80%–200%（每次 10%） | 唯一保留的设置，记在本机 |
| 一行字数 | 中文约 36 字（宽 36em），西文约 66 字符（宽 34em） | 按文章语言选 |
| 行高 | 中文 1.8，西文 1.65 | |
| 段落 | 图书：首行缩进 2 字、段距小、中文两端对齐；文章：不缩进、段距 1em、左对齐 | 按“图书 / 文章”自动选 |
| 字体 | 保持现在的默认（系统字体） | 不加网络字体，避免离线和加载问题 |
| 阅读方式 | **图书 + 宽屏（≥ 900px）= 单页翻页**；手机和文章 = 竖向滚动 | 没有“滚动 / 翻页”开关，没有双页 |
| 颜色 | 默认跟随系统；“护眼”按钮点一下换下一种 | 跟随系统 → 米黄 → 护眼绿 → 深色 → 回到跟随系统；按钮上显示当前颜色，换的时候弹一句名字 |

旧的阅读设置（行距、宽度、字体、段距、缩进、对齐、阅读方式、双页）在读取时**忽略**，不删用户本机的数据，但不再起作用；旧的颜色选择（跟随 / 浅 / 深 / 米黄 / 绿）保留，作为护眼循环的起点。

### 界面

- **图书章节的顶栏**：返回 · 书名 / 章名 · 上一章 / 下一章 · 目录（章节面板）· 翻译（能翻译才出现）· 专注阅读 · 护眼。去掉：阅读设置 Aa、保存、书签、星标、新标签打开。
- **文章的顶栏**：返回 · 标题 · 上一篇 / 下一篇 · 目录 · 翻译 · 专注阅读 · 保存 · 书签（只有已在书架里的）· 护眼（占原来“新标签打开”的位置）。去掉：阅读设置 Aa、星标（精选）、编辑笔记（卡片上本来就有编辑按钮）、新标签打开。播放按钮（有音频才有）不动。
- **PDF 和 HTML 原样页面**：顶栏保持现在的样子，“新标签打开”照旧（原页面对它们就是内容本身），Aa 去掉，加护眼；底部没有字号窗（字号对它们本来就不起作用）。读不了、只能打开原站的链接，同样保留“新标签打开”。
- **底部悬浮窗**（电脑和手机，图书和文章）：`A−  100%  A+` 和读到哪（翻页：`第 3 / 12 页 · 第 5 章`；滚动：`45%`）。电脑上半透明，鼠标靠近变清楚；手机上点正文中间和顶栏一起出现 / 收起；手机上“上一章 / 下一章”也放进去（替换现在的 `reader-mobile-nav`）。专注阅读时它和顶栏一起收起。
- **电脑端翻页**：书页在屏幕**正中**，纸色的一页，两边是略深的底；页的左右两边各一个大的 `‹` `›`（点页边也能翻）；键盘 ← → / PgUp PgDn / 空格、滚轮、点击左右 30% 保持；**翻页有一个 200ms 的滑动**（尊重系统的“减少动态效果”）；最后一页再翻 = 下一章第一页，第一页回翻 = 上一章最后一页（R2 已做）；图片按页高等比缩放，居中。
- 含表格 / 代码 / 视频或图太多的章节仍自动用滚动（R2 的规则不变），没有设置了，所以也没有说明文字。
