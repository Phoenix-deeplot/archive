## 4. 设计约定（本阶段不实现）

### 4.1 可读性

审计表按 `source / URL / 类型 / API 状态码 / reason / 是否原站可见 / 是否 RSS 有全文 / 修复方案` 记录。`unreachable` 和超时优先排查网络、重定向、内容大小与服务端超时；`empty` 排查正文提取；`robots/login/paywall/blocked` 不通过绕过限制来解决。视频和纯音频使用播放器或原站入口，不作为文章正文提取失败来计数。修复应附回归样本，目标是提高**可合法读取来源**的成功率，而不是保证所有 URL 都可全文抓取。

### 4.2 翻译

- 标题：延续构建期批量翻译与缓存；原题始终保留，中文界面以中文小字辅助阅读。
- 正文：仅对已取得正文的文章，用户主动点击后按段落/小节翻译；保持段落顺序、链接与结构；可切原文。每次请求不得超过所选提供方的长度限制。
- 缓存键至少包括正文哈希、段落序号、源/目标语言和提供方版本；同一内容不重复计费。服务端限制单篇字数、匿名用户速率和每日字符预算；超限时显示原文及原因，不静默产生付费请求。
- 首选/备用提供方由配置控制；仅在超时/5xx/限流等可重试原因下切换，鉴权失败或预算用尽不盲目重试。所有凭据只在服务端。

### 4.3 内容来源

第一批验证 LibriVox 有声读物 API/RSS、Project Gutenberg 新书 RSS/书目、Open Library 热门书籍元数据。热门书单与在线阅读全文分开：书单可以只用书目和原站链接；正文/音频播放须逐源核查内容权利、地区与接口条件。中文热门小说不预设可抓取全文，优先找官方授权、开放许可或公共领域来源。

### 4.4 标题布局与极简阅读（待用户确认）

- 热榜、今日听什么保留可访问的主标题；宽屏标题/副标题同一行，窄屏副标题下一行。无重复大标题，首张内容卡不被标题区挤出首屏。
- 极简阅读默认只保留正文和轻量进度；点按空白唤出返回、目录、字号/主题，停顿后收起。系统返回键与页面返回键行为一致；不强制开启音乐、朗读或横滑切篇。
