### 接口约定

- 保持现有 `GET /api/hot` 的 `columns`、`platforms` 字段兼容；分类 ID 使用稳定英文键：`news`、`tech`、`ai`、`money`、`world`、`entertainment`、`learning`、`media`、`shopping`。`shopping` 默认不占主导航，可通过配置启用。
- 保持现有 `GET /api/hot?p=<id>&format=json` 兼容；新增 `period=day|week`，缺省为 `day`。`day` 返回平台当前榜，`week` 使用服务端保存的近 7 天榜单快照计算，不伪造上游不存在的“周榜”。
- 新增只读 `GET /api/hot/events?lang=zh&limit=...`，返回 `{ok, updated, events}`；事件字段至少包含 `id`、`title`、`category`、`last_updated`、`source_count`、`trend`、`items`。每个 `items` 只返回标题、短摘要、来源、发布时间、语言和原文 URL，不返回全文或图片副本。
- 新增受保护的刷新入口供计划任务调用；既有 `/api/hot` 调用方式和字段不变。数据库表单独迁移、幂等创建，不清理或重建已有表。
- 事件发现采用“跨来源自动候选 + 运营固定/忽略”的混合方式；来源数和更新时间用于呈现/排序，不代表事实核验或真实性结论。

### 热点来源与更新策略

- 首批优先复用已配置并核验的来源：GDELT DOC 2.0 用于跨语言事件发现；华尔街见闻用于中文财经新闻；OpenAI News 等官方源用于 AI 公司动态；arXiv 与 AI 新闻分开，归入学习/专业内容而不是“AI 最新新闻”。
- BBC、DW、RFI、半岛等已有 RSS 只在逐源确认展示/聚合条款后纳入；RSS 可读不等于可任意复制元数据。Bloomberg RSS 当前稳定性待测，未经许可不展示全文/市场数据；WSJ 不承诺存在可商用的免费聚合接口。黄金先追踪相关新闻，不提供无授权实时金价。
- 页面访问时允许按缓存策略刷新；榜单周期快照通过计划任务落库。Vercel Hobby 官方限制定时任务每天最多运行一次，因此首版按“页面访问时更新事件源 + 每日快照”设计，不承诺无人访问时每 15 分钟采集。若要无人访问时高频追踪，需要外部调度器或确认套餐支持，再单独配置。
- 推荐排序先采用可解释的默认权重：新鲜度 25%、来源可用性 20%、站内打开/阅读能力 20%、曝光归一后的打开/收藏表现 25%、人工精选 10%。低样本时保留探索位并回退到人工顺序；只有采集到有效曝光数据后才启用互动项。
- 上游榜单自身名次保持原样。动态权重只调整“榜单入口/跨源精选/热点事件”顺序；采集失败连续发生时先降权并标注更新时间，达到暂停阈值后隐藏但保留配置。

### 改动范围

1. 前端以“平台榜单 / 热点追踪”为清晰主入口；平台榜单更靠前、更显眼。移动端压缩多层横向选项，电脑端保留便于快速浏览的分类与榜单导航。
2. “今天有什么值得看”缩为最多 1–3 张今日焦点卡，只在有新鲜、有效内容时显示；不再用大块说明区挤压榜单内容。
3. 增加今日/近 7 天切换；近 7 天展示明确的汇总口径与更新时间，不把“某平台原生周榜”与“本站快照汇总周榜”混称。
4. API 分类重整并迁移旧 `play` 等偏好键；为现有平台指定一个主要场景分类，避免同一来源重复占满分类。AI 栏只放 AI 新闻；论文/专业研究另归学习与专业提升。
5. 增加事件列表与简要事件详情：例如伊以局势、俄乌、黄金相关新闻。支持自动合并标题相近报道、显示多来源更新、冷却/归档；首版热点摘要仅基于来源短摘要或人工文案，不自动编造事实结论。
6. 新增存储事件、来源报道、榜单快照所需的幂等数据库迁移；新增只读 API 和受保护刷新入口。没有数据库配置时返回明确可诊断状态，不静默伪造周榜。
7. 来源管理首版沿用可审阅的源配置；不在本次扩建完整运营管理后台。收集到真实互动数据后再校准公式，避免以小样本点击数重排。

### 风险和要避开的冲突点

- 当前榜单服务只缓存“此刻”的平台结果，不存历史；周榜与事件追踪需要新的持久化层，不能只改前端按钮。
- Vercel Hobby 只能每天执行一次 Cron；高频后台追踪依赖额外调度器/套餐。首版通过访问时更新事件源降低成本，界面必须展示真实更新时间。
- 对标题相似度聚类，冲突/财经话题容易误合并；保留来源链接、事件别名和人工忽略机制，允许后续拆分。
- GDELT 适合找跨来源报道和趋势，不是事实核验来源；新闻源的 RSS/接口与内容授权分开检查。
- `index.html` 是大型单文件，只编辑热榜相关样式/函数与测试，避免改动发现页、书架、阅读器及翻译词典。
- 现有工作区有未跟踪用户文件，任何分支都不得 add、修改或删除。
