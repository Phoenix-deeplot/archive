本任务在当前会话仅由 Codex 执行；没有分配 Claude 工作，避免两个工作目录同时修改 `index.html`。

### 接口约定

- 不新增或修改 API、数据格式、订阅源配置及外部服务。
- 继续使用现有 `embedOf(url)` 的平台解析结果及 `openEmbed(...)` 的原站链接；不绕过平台登录墙、地区限制或播放权限。
- 若嵌入无法播放，用户可使用现有原站地址打开内容。

### 验收

- 桌面端观看弹窗能更充分利用可用视口，视频保持合适比例，标题、来源和原站入口清晰可操作。
- 移动端视频区域不溢出屏幕；关闭、原站跳转等操作易于触达；横竖屏均可正常布局。
- 非视频内容及现有音乐播放弹窗不回归。
- 对 `index.html` 执行 JavaScript 语法检查并检查重复函数声明；在本地预览中用桌面与手机视口检查 Bilibili、YouTube 及不支持嵌入的 URL 回退。
- 不合并、不推送、不部署；完成后提供本地预览方式供用户验收。

### 风险和要避开的冲突点

- `index.html` 是大型单文件应用；只改播放器弹窗相关 CSS/JS，避免改共享词典、推荐逻辑和卡片布局。
- 第三方 iframe 的登录状态、广告、地区可用性和播放权限由平台决定，本项目不能保证站内必播；必须保留原站回退。
- 需要真实的用户态播放诊断或新增源时，应另建任务并明确接口及版权/平台许可，不在本轮扩展范围。
